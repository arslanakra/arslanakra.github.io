    Critical bugs caught

    03 case studies
    BUG-001 · FINANCIAL DATA CRITICAL

    Incorrect fund mapping & sign inversion

    Check Cashing Web App · Money Transfer

    Impact

    Misclassified transactions and incorrect debit totals in daily financial reporting.

    Investigation details

    The API returned an additional-service amount in the maxi parameter, but the frontend displayed it under intermex, assigning transactions to the wrong category. Negative API amounts were also converted to positive values by the React component, causing debit totals to mismatch.

    StatusFIXED

    BUG-002 · OCR & ACCESS CONTROL CRITICAL

    OCR failure payload & terminal access scope

    Agent POS System

    Impact

    Unverified checks could proceed, and users could transact outside their assigned terminal.

    Investigation details

    When Gemini OCR failed, check and owner information was still forwarded to the maker instead of blocking submission on an empty or invalid payload. Separately, users assigned to Terminal 890 could authenticate and transact on Terminal 891.

    StatusFIXED

    BUG-003 · MOBILE NAVIGATION CRITICAL

    Stale navigation after app flow changes

    MySalarium · Send Money App

    Impact

    Users could land on detached Wallet or Prepaid screens instead of the intended flow.

    Investigation details

    After Wallet and Prepaid were detached, relaunching from the calculator could route back to the obsolete Wallet screen. Completing sign-in and registration could also open Prepaid rather than the intended recipients list.

    StatusFIXED
